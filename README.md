# Data Structures & Algorithms Assignment

This repository contains professional C++ implementations for a comprehensive set of Data Structure . Each solution is optimized for performance and follows strict algorithmic constraints.

## 🚀 Problems Implemented

### 1. Updated Binary Search (Problem 2)
*   **Description:** Enhanced Binary Search to handle **Rotated Sorted Arrays**.
*   **Key Features:** 
    *   Optimized to handle duplicate elements.
    *   Tracks total element-to-element comparisons.
*   **Complexity:** Average $O(\log n)$, Worst $O(n)$ due to duplicates.

### 2. Bitonic Array Search (Problem 3)
*   **Description:** Sorting an unsorted array into a **Bitonic Form** (Ascending then Descending).
*   **Algorithms Used:** Bubble Sort (Left Half) & Selection Sort (Right Half).
*   **Search:** Implements Linear Search to find target elements.

### 3. Round Robin CPU Scheduler (Problem 4)
*   **Description:** A simulation of the **Round Robin (RR)** scheduling algorithm.
*   **Logic:** Uses `std::queue` to manage process execution order based on Arrival Time and Time Quantum.
*   **Features:** Displays step-by-step "Queue Updates" and calculates Completion, Turnaround, and Waiting times.

### 4. Stack Applications (Problem 5)
*   **Math Expression Evaluator:** Parses and evaluates strings with `+`, `-`, `()`, and unary minus without using `eval()`.
*   **Circular Next Greater Element:** Uses a **Monotonic Stack** to find the next larger number in a circular integer array in $O(n)$ time.
